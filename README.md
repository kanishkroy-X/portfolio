## Overview

Personal portfolio and systems archive designed as an **editorial product studio × technical notebook**. It documents end-to-end product architecture, AI workflows, and design engineering with authentic evidence, interactive media, and structured case studies.

### Key Highlights

* **3-Mode Theme Engine**: Seamless Light, Dark, and System preference detection with zero Flash of Unstyled Content (FOUC) and persistent state.
* **Curated Design Tokens**: Calibrated contrast for both day and night viewing, paired with a modern typography stack (`Geist Sans` & `Inter`).
* **Interactive Media Players**: Responsive commercial showcases supporting dynamic switching between 9:16 vertical and 16:9 widescreen video assets with custom poster frames.
* **Verified Project Evidence**: In-depth case studies with real architectural diagrams, state flow models, and benchmarked metrics.

## Tech Stack

* **Framework:** [Astro 5.x](https://astro.build/) (Static Site Generation / SSG)
* **Styling:** [Tailwind CSS 4.x](https://tailwindcss.com/) + CSS Custom Properties Design Tokens
* **Typography:** Geist Sans, Inter, System Fallbacks
* **Type Safety:** TypeScript Strict Mode
* **Deployment:** [Vercel](https://vercel.com/) (Automated CI/CD via GitHub Integration)

## Local Development

```bash
# Clone repository
git clone https://github.com/kanishkroy-X/portfolio.git
cd portfolio

# Install dependencies
npm install

# Start local development server
npm run dev

# Run type check and diagnostics
npx astro check

# Production build
npm run build

# Preview production build locally
npm run preview
```
