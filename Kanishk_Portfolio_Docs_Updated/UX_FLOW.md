## How I Work
Four-step methodology:
1. **DECONSTRUCT** — understand the problem before touching the tools
2. **BUILD** — turn the idea into a working system
3. **TEST** — look for failure points, friction, inconsistencies
4. **REFINE** — improve based on what actually happens

Paired with the six-icon system:
Build · Experiment · AI Systems · Create · Improve · Share

The icons complement the four-step methodology; they do not create a second competing process.
